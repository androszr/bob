# Template: Status update / sync (Meeting Notes)

> **What this template is for (read carefully before you choose it):**
> - A **status / sync / progress update** meeting — regular (weekly, fortnightly) or ad hoc check-ins.
> - Main goal: **sharing information about progress**, identifying blockers, updating risks. **No strategic decisions are made here**, and no AS IS / TO BE processes are mapped.
> - Participants report what they did, what they are doing and what is blocking them — in a format similar to a daily stand-up, but at the level of a week/sprint/initiative.
>
> **When NOT to use:**
> - if the meeting had one specific problem to settle → use `meeting-notes-decision.template.md`
> - if it was a process-mapping workshop with the business → use `meeting-notes-as-is-to-be.template.md`
> - if the team was wrapping up a completed stage → use `meeting-notes-retrospective.template.md`
> - if it was the start of a new initiative → use `meeting-notes-kickoff.template.md`
> - if it was a qualitative / discovery interview with a single interviewee → use `meeting-notes-discovery-interview.template.md`
> - if it was an observation at the workplace / shadowing → use `meeting-notes-contextual-inquiry.template.md`
> - if it was an evaluation interview about an existing product → use `meeting-notes-product-feedback-interview.template.md`
>
> **How to use:**
> - Fill it in from the audio transcript (`*.mp3.json`), your own notes or Slack.
> - For each workstream, briefly: progress since last time → what is planned → what is blocking.
> - **Convert relative dates to absolute ones** (e.g. "next week" → "week of 2026-05-22").
> - Name the file: `status-{initiative-kebab}-{YYYY-MM-DD}.md` or `sync-{team}-{YYYY-MM-DD}.md`.
