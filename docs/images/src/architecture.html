Five pieces. One loop.

A new message comes in, the model writes a reply with the tools this chat is allowed, and the reply goes back from your own account, labelled.

1Microsoft Teams
web client's internal API,
called with the owner's session token
⇅new messages / reply
2The agent
watch loop · prompt builder
chat history · per-chat knowledge
⇅prompt / answer
3claude CLI
no shell · no file-editing tools
allow-listed tools only
⇅tool calls
4MCP servers
jira-read · jira · todos · leave
datetime · md-to-mp3
↓lookups / Jira writes
5Team data
Jira · SharePoint leave sheet
1Your own session. No bot registration: replies are posted from your account and carry the [Bob] label.
2One chat, one rule set. Each chat names its persona, its tools and its knowledge.
3A boxed-in model. One CLI call per reply, with an explicit tool list.
4Local tool servers. As daemons they listen on 127.0.0.1 and need a bearer token.
Playwright Chromium
sign-in · keepalive · file uploads
