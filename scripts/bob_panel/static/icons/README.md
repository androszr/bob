# Panel icons

Hand-drawn 16 px stroke icons (16-unit grid, 1.6 stroke, round caps) used by the panel page through a
CSS mask, so they take the colour of the surrounding text. They were drawn for this project and are released under
CC0 (public domain): copy, change and ship them freely.

`cross`, `settings`, `user`, `schedule`, `dashboard`, `chatbubbles`, `tick`, `shield`, `info`, `warning`
